# 🏠 Real Estate Calling Bot

An automated voice calling system for real estate agencies using **Bland AI** for intelligent calls and **Google Sheets** as a database. Built with Flask REST API.

## ✨ Features

- 🤖 Automated voice calls using Bland AI
- 📊 Google Sheets as a lightweight database for leads
- 📞 Call scheduling and batch calling
- 📝 Call logging and analytics
- 🔄 Real-time webhook callbacks
- 📱 RESTful API for easy integration

## 🛠 Tech Stack

- **Backend**: Flask (Python)
- **Database**: Google Sheets API
- **Voice AI**: Bland AI API
- **Deployment**: Any cloud platform (Render, Heroku, AWS)

## 📋 Prerequisites

- Python 3.9+
- Google Service Account credentials
- Bland AI API key
- Google Cloud Project with Sheets API enabled
